## Tips
- 16:10 aspect ratio looks cleanest in the browser frame
- Compress with squoosh.app to keep page weight low
- For a consistent look, take all screenshots in dark mode at 1600×1000
- If you don't have a real screenshot yet, leave the file out — the CSS mock UI will render in its place

## Generated by AI?

You can generate placeholder UI screenshots with:
- Midjourney prompt: `interface design, modern dark UI dashboard for {project}, glass morphism, mono typography, 16:10 ratio, marketing screenshot`
- DALL·E / GPT image: `Create a screenshot of {project} in a modern dark theme, similar to Linear or Vercel dashboards, 16:10`
- Just drop the result here with the file name above.
